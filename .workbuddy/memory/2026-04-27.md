# 2026-04-27 开发日记

## 今日主要工作

### 问题1：写入日志失败
- **原因**：DbHelper 使用 `context.getDatabasePath()` 在 system_server 环境下解析到 `/data/data/android/databases/`
- **修复**：硬编码绝对路径 `/data/data/com.android.clipboardguard/databases/clipboardguard.db`

### 问题2：编译错误
- **错误1**：`super()` 必须放在构造函数第一行 → 内联路径字符串到 super() 调用中
- **错误2**：XmlPullParserFactory 不在 Android SDK 中 → 改用正则表达式解析 XML

### 问题3：未勾选应用仍弹窗
- **原因**：App 写数据到 SQLite + SharedPreferences，但 system_server 只读 SQLite
- **SELinux 阻止 DB 访问时**，所有查询返回 -1（默认拦截），导致每次都弹窗
- **修复**：在 PermissionCache 中增加 SharedPreferences 回退读取逻辑
  - `querySharedPreferencesDirect()`：直接读取 SP XML 文件并用正则解析 `<int name="perm_xxx" value="N" />`
