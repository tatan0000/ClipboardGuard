# 2026-05-01 工作日志

## 修复规则开关同步问题

### 问题
用户反馈：从规则详情页打开/关闭开关后，返回应用页时开关状态不同步。

### 根因
- `initWriteRulesEntry()` 和 `initReadRulesEntry()` 只在 `onCreate()` 调用一次
- `onResume()` 没有刷新规则开关状态
- 双向同步不完整

### 修复
1. MainActivity.onResume() - 新增 `refreshRulesSwitches()` 调用
2. WriteRulesDetailActivity - 新增 `onResume()` 刷新开关
3. ReadRulesDetailActivity - 新增 `onResume()` 刷新开关

### 验证
BUILD SUCCESSFUL

## 性能优化（20:45）

### 问题
用户反馈打开规则详情页时"卡了一下"，日志显示：
- `Skipped 82 frames!`
- Activity 启动耗时 1.4s

### 根因
所有文件 I/O 操作（loadWriteRulesSync、loadDefaultWriteRules 等）均在主线程执行。

### 修复
1. 新增 `ExecutorService` 后台线程
2. 读写 JSON 文件移至后台线程
3. UI 刷新切回主线程（Handler.post）

### 结果
BUILD SUCCESSFUL
