# 2026-04-21 日志

## 资源优化

### 严重Bug修复
- `checkbox_custom.xml`：修复非法 `<vector>` 嵌套在 `<layer-list><item>` 里，改为直接写 `<path>` 节点。
  原因：Android 遇到无法解析的内嵌 vector 会跳过整个 item，导致对勾图标在部分设备/ROM 上完全不可见。

### 资源清理
删除了 13 个孤立资源（无任何引用）：
- `bg_card.xml`, `bg_search_box.xml`, `bg_search_box2.xml`, `btn_reset_bg.xml`
- `ic_arrow_drop_down.xml`, `ic_back.xml`, `ic_xposed.xml`
- `selector_radio_theme.xml`, `radio_checked.xml`, `radio_unchecked.xml`
- `ic_save.xml`（与 ic_check 完全重复）
- `bg_btn_go_settings.xml`（回滚后不再需要）

### 深色模式适配
6 个导航/指示图标从硬编码 `#000000`/`#FF000000` 改为 `?attr/colorOnSurfaceVariant` 主题属性。

## 代码重构

### MainActivity.java
- 修复静态初始化非法前向引用（`sCurrentPage = PAGE_HOME` → `sCurrentPage = 0`）
- `sInstance` 改为 `WeakReference<MainActivity>` 防内存泄漏
- 主题常量改为引用 `ClipboardGuardApp` 避免三处重复定义
- `showPage()` 只在切到 PAGE_APPS 时才刷新权限

### Hook.java
- 删除死代码 `sLastPopupTime` Map
- 删除冗余 `sThreadHandled.set(true)` 调用
- 防抖记录时机修正：弹窗结束才写入真实决策
- 简化 `afterHookedMethod` 逻辑

### PermissionStorage.java
- 去掉废弃的 SharedPreferences / 文件 fallback 路径，统一走 ContentProvider
- `HashMap` 改为 `Collections.synchronizedMap`

### PermissionProvider.java
- 修复 `query()` 中 pending Cursor 双关闭问题
- 修复 `delete()` → `resetPermission()` → `savePermission()` → `call()` 死递归，改直接写库
- `update()` 语义改为真正更新而非转发

### LogAdapter.java
- `SimpleDateFormat` 改为静态共享，避免每次 `bind()` 创建新实例

### PermissionResultReceiver.java
- try-with-resources 管理 Cursor，线程改为 daemon

### DialogLaunchReceiver.java
- 修复 `getRunningAppProcesses()` 空指针
