# 2026-04-18 工作日志

## 底部导航栏间距调整 + 布局修复
- 首页 `page_home` 的 `paddingBottom` 经过多次调整：80dp → 64dp → 8dp(clipToPadding) → 16dp → 20dp → 64dp(clipToPadding) → 24dp → 72dp → 80dp → 64dp → **56dp（最终确认）**
- `clipToPadding="false"` 会导致内容覆盖到导航栏上，不可用

### 重大布局问题发现与修复
- 文件中出现了一个**游离的 LinearLayout**（用 `layout_anchor` 锚定在 frameLayout 上），把所有首页卡片内容挂在了 CoordinatorLayout 中间位置
- 导致：AppBarLayout（顶栏）和 bottom_nav（底栏）都被挤掉/不显示
- **根因**：之前的某次编辑中，NestedScrollView 内部的卡片内容被错误地移到了外部作为一个独立的锚定视图，而 NestedScrollView 变成了空壳
- **修复**：
  1. 将所有卡片内容（状态卡片、信息卡片、使用说明卡片）移回 NestedScrollView 内部
  2. 删除了游离的 `app:layout_anchor="@+id/frameLayout"` LinearLayout
- 最终确认 padding 为 **56dp**
