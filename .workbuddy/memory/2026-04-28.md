## FAB 自动隐藏功能

### 需求
右下角保存按钮（FAB），在应用页无操作 2 秒后自动隐藏。

### 实现方式
- `mFabAutoHide` Runnable：2s 后执行淡出动画（alpha 0 + scale 0.5 → GONE）
- `resetFabAutoHide()` 方法：
  - 取消旧倒计时
  - 若 FAB 已隐藏则恢复显示（alpha/scale 归 1 + VISIBLE）
  - 重新 postDelayed 2s
- 触发重置倒计时的交互点：
  - 进入 PAGE_APPS
  - 列表项点击切换勾选
  - 搜索框输入
  - 全选/反选按钮点击
  - 分组头全选 CheckBox 点击
  - FAB 保存按钮点击
- 离开应用页时取消倒计时（防止泄漏）
- 文件：`MainActivity.java`
- 常量：`FAB_AUTO_HIDE_DELAY = 2000L`

## FAB 显示逻辑优化（18:57）

### 需求变更
进入应用页时 FAB 隐藏，只要有操作（勾选/搜索等）就显示 FAB。

### 修改内容
1. **showPage(PAGE_APPS)**：移除 `mFab.setVisibility(View.VISIBLE)` 及 `resetFabAutoHide()` 调用，改为 `mFab.setVisibility(View.GONE)`
2. **resetFabAutoHide()**：保持原有逻辑不变（有操作时显示 FAB）

### 效果
- 初始进入应用页：FAB 隐藏
- 勾选/取消勾选/搜索/全选/触摸列表/滑动列表/展开折叠分组：FAB 显示
- 无操作 4 秒：FAB 淡出隐藏
- 常量：`FAB_AUTO_HIDE_DELAY = 4000L`
- 退出应用页或切换页面：停止倒计时（`showPage()` 中 `removeCallbacks`，防止内存泄漏）
- 文件：`MainActivity.java`
